#           Core Infrastructure Services Comparison
---

| Infrastructure Component | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud Platform (GCP) |
|---|---|---|---|
| **Compute** | Amazon EC2 (Elastic Compute Cloud) | Azure Virtual Machines | Google Compute Engine (GCE) |
| **Storage** | Amazon S3 (Simple Storage Service) | Azure Blob Storage | Google Cloud Storage (GCS) |
| **Networking** | Amazon VPC (Virtual Private Cloud) | Azure Virtual Network | Google Cloud VPC |
| **Identity and Access Management (IAM)** | AWS IAM | Azure Active Directory (Azure AD) | Cloud Identity & Access Management (Cloud IAM) |

---

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) offers the broadest range of services. AWS has the longest history in the cloud market and provides over 200+ fully featured services spanning compute, storage, databases, analytics, machine learning, and enterprise applications. Its massive ecosystem means almost any business or technical need has a dedicated service available.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure is the best choice for organizations using Microsoft products. Azure integrates seamlessly with Windows Server, Active Directory, Microsoft 365, SQL Server, and .NET. Since both the software and the cloud platform come from Microsoft, compatibility is guaranteed, management is unified, and authentication works through existing accounts without extra setup.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform (GCP) is widely recognized for AI, ML, and Kubernetes. Google invented Kubernetes and continues to lead container orchestration with Google Kubernetes Engine (GKE). GCP also offers advanced AI and ML tools built on the same technology Google uses internally, making it the top choice for intelligent applications.

### 4. What similarities did you observe among the three cloud providers?
All three providers offer the same core infrastructure services — virtual machines for compute, object storage, virtual private networking, and identity management. They all follow the pay-as-you-go pricing model, provide global regions and availability zones, and support standard Linux and Windows operating systems. While the names differ, the fundamental purpose and capabilities are nearly identical across all three.
