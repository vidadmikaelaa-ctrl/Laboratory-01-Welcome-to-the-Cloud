
# Laboratory 05: The Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud storage and the deployment of an S3-compatible Object Storage server using MinIO and Docker. The activity demonstrates how to create a storage bucket, access a cloud storage web interface, and upload a sample file using the MinIO Console.

The project uses KillerCoda Ubuntu and Docker to deploy MinIO. A bucket named `client-photos` was created to represent a storage location for user-uploaded images in a photo-sharing application.

## Objectives

- Differentiate between Block Storage, File Storage, and Object Storage.
- Deploy an S3-compatible Object Storage server using Docker.
- Access the MinIO Web Console through port 9001.
- Create a cloud storage bucket.
- Upload a sample file to the storage bucket.
- Document the deployment and storage operations using Markdown.
- Organize cloud computing laboratory evidence in a GitHub repository.

## Tools Used

- MinIO Web Console

## Skills Learned

- Understanding different types of cloud storage.
- Deploying a containerized storage service.
- Using Docker environment variables.

- Uploading files to MinIO.
- Writing technical documentation using Markdown.
- Organizing screenshots and project files in GitHub.
