# Final Reflection — Mission 1 to Mission 10

Throughout our Cloud Computing laboratory activities, I learned how cloud infrastructure works and how important it is to manage servers properly. The activities helped me improve my technical skills, problem-solving abilities, and understanding of system administration.

For our final mission, I created the CloudNova Enterprise project using Ubuntu Server, Oracle VirtualBox, Docker, WordPress, and MySQL. I learned how to connect to a Linux server using SSH, configure a firewall, deploy Docker containers, and manage persistent database storage.

One of the most challenging parts was setting up automated backups and testing database restoration. I encountered problems with Linux commands, file locations, and terminal operations. By troubleshooting these issues, I learned how to identify errors, verify commands, and check whether my backups were working.

I also created an architecture diagram and operational manual to document the system. This helped me understand why proper documentation is important when managing cloud infrastructure.

Overall, this final mission taught me that cloud computing is not only about deploying applications but also about security, automation, reliability, and maintenance. I gained more confidence in using Linux and Docker, and I now have a better understanding of the responsibilities of a cloud infrastructure administrator.
